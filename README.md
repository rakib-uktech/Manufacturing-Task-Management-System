## Overview
The Manufacturing Task Management System is an internal production management platform designed to manage operational workflows within manufacturing environments.

The system improves production visibility by enabling supervisors and managers to track tasks, manage shifts, schedule work orders, and monitor production performance in real time.

## Key Features

### Task Management
- Assign production tasks to operators
- Track task completion status
- Monitor productivity

### Shift Management
- Manage production shifts
- Assign operators to shifts
- Track shift performance

### Work Order Management
- Create and schedule production work orders
- Monitor work order progress
- Generate production reports

### Production Reporting
- Track operational efficiency
- Generate task completion statistics
- Provide management-level production insights

---

## System Architecture

The system follows a typical **3-tier architecture**:

User Interface → Application Logic → Database

Frontend:
- ASP.NET Core Razor Pages
- JavaScript
- HTML / CSS

Backend:
- C#
- ASP.NET Core

Database:
- SQL Database

Cloud Infrastructure:
- AWS EC2
- AWS Elastic Beanstalk
