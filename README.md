## Overview

The Manufacturing Task Management System is an internal production management platform built to bring structure and visibility to day-to-day manufacturing operations. It gives supervisors and managers a single place to assign and track production tasks, manage shifts, schedule and monitor work orders, and review production performance in real time — replacing the fragmented spreadsheets and paper records that typically sit behind manufacturing scheduling.

The platform was independently designed, developed, and deployed by me, and is currently in active daily use across manufacturing operations.

---

## Key Features

**Task Management**
- Assign production tasks to operators
- Track task completion status in real time
- Monitor individual and team productivity

**Shift Management**
- Configure and manage production shifts
- Assign operators to shifts
- Track shift-level performance

**Work Order Management**
- Create and schedule production work orders
- Monitor work order progress end to end
- Generate production reports on demand

**Production Reporting**
- Track operational efficiency across the production floor
- Generate task completion statistics
- Provide management-level production insights and KPIs

## System Architecture

The application follows a standard three-tier architecture:

```
User Interface  →  Application Logic  →  Database
```

**Frontend**
- ASP.NET Core Razor Pages
- JavaScript
- HTML / CSS

**Backend**
- C#
- ASP.NET Core

**Database**
- SQL Database

**Cloud Infrastructure**
- AWS EC2
- AWS Elastic Beanstalk

```bash

```

```bash
dotnet run
```
